# PSL – Premier Soccer League

A simple NBA.com-style website for a fictional soccer league, built with **React (Vite)** on the frontend and **Node.js (Express)** on the backend.

> The original static coaching site (`index.html`, `styles.css`, `script.js`, `preview.html`) is left untouched at the repo root.

## Features

- **Live-style score ticker** across the top with latest results and upcoming fixtures
- **Home page** with a top story hero, latest headlines, this matchday's fixtures, mini standings and stat leaders
- **Scores & Schedule** with a matchday picker and goal scorers for every finished match
- **Standings** table with form guide and qualification/relegation zones
- **Teams** directory and **team pages** with record, recent results, upcoming games and full roster
- **Player stats** leaderboards (goals, assists, clean sheets, appearances)
- **News** list and article pages
- Responsive layout with a mobile menu

All data is generated by the server from a fixed seed (`server/data.js`): 10 teams, 160 players, an 18-matchday double round-robin season anchored to today's date, with standings and player stats computed from the simulated results.

## Project structure

```
server/          Express API (port 4000)
  data.js        Seeded mock data: teams, players, games, standings, news
  index.js       REST endpoints + serves client/dist in production
client/          React app (Vite, port 5173 in dev)
  src/pages/     Home, Scores, Standings, Teams, TeamPage, Stats, News, Article
  src/components Header, ScoreTicker, GameCard, StandingsTable, NewsCard, ...
```

## Getting started

Requires Node.js 18+.

```bash
npm install        # installs server + client (npm workspaces)
npm run dev        # API on :4000 and Vite dev server on :5173 (proxies /api)
```

Open http://localhost:5173.

### Production

```bash
npm run build      # builds the React app into client/dist
npm start          # Express serves the API and the built site on :4000
```

## API

| Endpoint | Description |
| --- | --- |
| `GET /api/league` | League info and current matchday |
| `GET /api/teams` | All teams |
| `GET /api/teams/:id` | Team with standing, roster and games |
| `GET /api/games?matchday=&status=&team=` | Fixtures and results |
| `GET /api/games/:id` | Single game |
| `GET /api/standings` | League table |
| `GET /api/players?sort=goals\|assists\|apps\|cleanSheets&team=&limit=` | Players / leaderboards |
| `GET /api/news` / `GET /api/news/:id` | News articles |

Note: `rollup` is pinned via `overrides` in the root `package.json` because Rollup 4.64 hangs while bundling `react-dom` with Vite 6.
